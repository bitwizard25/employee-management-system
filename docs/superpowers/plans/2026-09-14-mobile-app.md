# Mobile App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the React Native Android app for the employee attendance & location tracking system — Google sign-in, role-based navigation (employee vs admin, same login), geofence-based clock in/out, continuous location tracking while clocked in, and an in-app admin suite.

**Architecture:** React Native (bare CLI) + TypeScript, consuming the NestJS backend built in the companion backend plan. React Context for the auth session, TanStack Query for all server data. A geofence watcher (foreground service) drives local clock-in/out prompts and a location-ping timer while clocked in. NativeWind (Tailwind CSS syntax) for styling throughout.

**Tech Stack:** React Native (bare CLI), TypeScript (strict), NativeWind, React Navigation, TanStack Query (`@tanstack/react-query`), `@react-native-google-signin/google-signin`, `react-native-keychain`, `react-native-geolocation-service`, `react-native-background-actions`, `@notifee/react-native`, `react-native-maps`, Jest + `@testing-library/react-native`.

**Spec:** `docs/superpowers/specs/2026-09-14-employee-attendance-system-design.md`

**Depends on:** the backend API built in `docs/superpowers/plans/2026-09-14-backend-api.md` (all endpoints in this plan already exist and are tested).

## Global Constraints

- TypeScript strict mode in `mobile`.
- All HTTP calls go through the single `src/api/client.ts` — no screen or
  service calls `fetch` directly. The client attaches the `Authorization`
  header and transparently refreshes an expired access token once before
  retrying a request that got a 401.
- Auth tokens are stored via `react-native-keychain` only — never
  `AsyncStorage`, never plain component state persisted to disk.
- Continuous location pings are only ever sent while the user has an open
  attendance record; the ping timer must be stopped immediately on
  clock-out (mirrors the backend's own guard on `POST /location/ping`).
- A geofence crossing never auto clocks the user in/out — it only shows a
  local notification the user must tap to confirm (per spec section 7).
- Every screen that lists server data (employees, offices, attendance,
  reports) renders explicit loading and error states, not just the happy
  path.
- No native permission (location, notifications) is requested until the
  screen that needs it is actually reached — not eagerly at app launch.

import * as Keychain from 'react-native-keychain';

export interface StoredTokens {
  accessToken: string;
  refreshToken: string;
}

const SERVICE = 'attendanceApp';

export async function saveTokens(tokens: StoredTokens): Promise<void> {
  await Keychain.setGenericPassword(SERVICE, JSON.stringify(tokens));
}

export async function getTokens(): Promise<StoredTokens | null> {
  const result = await Keychain.getGenericPassword();
  if (!result) return null;
  return JSON.parse(result.password) as StoredTokens;
}

export async function clearTokens(): Promise<void> {
  await Keychain.resetGenericPassword();
}
```

import { API_BASE_URL } from './config';
import { getTokens, saveTokens } from '../auth/tokenStorage';

export class ApiError extends Error {
  status: number;
  constructor(status: number, message: string) {
    super(message);
    this.status = status;
  }
}

async function rawFetch(path: string, accessToken: string, options: RequestInit) {
  return fetch(`${API_BASE_URL}${path}`, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${accessToken}`,
      ...options.headers,
    },
  });
}

async function refreshAccessToken(refreshToken: string): Promise<string> {
  const response = await fetch(`${API_BASE_URL}/auth/refresh`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ refreshToken }),
  });
  if (!response.ok) {
    throw new ApiError(response.status, 'Session expired, please sign in again');
  }
  const { accessToken } = await response.json();
  return accessToken;
}

export async function apiFetch<T>(path: string, options: RequestInit = {}): Promise<T> {
  const tokens = await getTokens();
  if (!tokens) {
    throw new ApiError(401, 'Not signed in');
  }

  let response = await rawFetch(path, tokens.accessToken, options);

  if (response.status === 401) {
    const newAccessToken = await refreshAccessToken(tokens.refreshToken);
    await saveTokens({ accessToken: newAccessToken, refreshToken: tokens.refreshToken });
    response = await rawFetch(path, newAccessToken, options);
  }

  const body = await response.json();
  if (!response.ok) {
    throw new ApiError(response.status, body.message ?? 'Request failed');
  }
  return body as T;
}
```

import { API_BASE_URL } from '../api/config';
import { ApiError } from '../api/client';

export interface AuthUser {
  id: string;
  email: string;
  name: string;
  role: 'employee' | 'admin';
}

export interface LoginResult {
  accessToken: string;
  refreshToken: string;
  user: AuthUser;
}

export async function loginWithGoogle(idToken: string): Promise<LoginResult> {
  const response = await fetch(`${API_BASE_URL}/auth/google`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ idToken }),
  });
  const body = await response.json();
  if (!response.ok) {
    throw new ApiError(response.status, body.message ?? 'Login failed');
  }
  return body as LoginResult;
}
```

import React, { createContext, useContext, useEffect, useState, useCallback } from 'react';
import { signInWithGoogle, signOutOfGoogle } from './googleSignIn';
import { loginWithGoogle, AuthUser } from './authApi';
import { getTokens, saveTokens, clearTokens } from './tokenStorage';

type AuthStatus = 'loading' | 'signedOut' | 'signedIn';

interface AuthContextValue {
  user: AuthUser | null;
  status: AuthStatus;
  login: () => Promise<void>;
  logout: () => Promise<void>;
}

const AuthContext = createContext<AuthContextValue | undefined>(undefined);

export function AuthProvider({ children }: { children: React.ReactNode }) {
  const [user, setUser] = useState<AuthUser | null>(null);
  const [status, setStatus] = useState<AuthStatus>('loading');

  useEffect(() => {
    getTokens().then((tokens) => {
      // Tokens on disk don't carry the user profile; a full session
      // restore (re-fetching /users/me) is a follow-up, not required by
      // this plan's scope — start signed out and require a fresh login.
      setStatus(tokens ? 'signedOut' : 'signedOut');
    });
  }, []);

  const login = useCallback(async () => {
    const { idToken } = await signInWithGoogle();
    const result = await loginWithGoogle(idToken);
    await saveTokens({ accessToken: result.accessToken, refreshToken: result.refreshToken });
    setUser(result.user);
    setStatus('signedIn');
  }, []);

  const logout = useCallback(async () => {
    await signOutOfGoogle();
    await clearTokens();
    setUser(null);
    setStatus('signedOut');
  }, []);

  return (
    <AuthContext.Provider value={{ user, status, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth(): AuthContextValue {
  const ctx = useContext(AuthContext);
  if (!ctx) throw new Error('useAuth must be used within an AuthProvider');
  return ctx;
}

import React, { useState } from 'react';
import { View, Text, Pressable, ActivityIndicator } from 'react-native';
import { useAuth } from '../../auth/AuthContext';

export function LoginScreen() {
  const { login } = useAuth();
  const [pending, setPending] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const handleLogin = async () => {
    setPending(true);
    setError(null);
    try {
      await login();
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Login failed');
    } finally {
      setPending(false);
    }
  };

  return (
    <View className="flex-1 items-center justify-center bg-white px-6">
      <Text className="mb-8 text-2xl font-bold">Employee Attendance</Text>
      <Pressable
        onPress={handleLogin}
        disabled={pending}
        className="rounded-md bg-blue-600 px-6 py-3"
      >
        {pending ? (
          <ActivityIndicator color="white" />
        ) : (
          <Text className="font-semibold text-white">Sign in with Google</Text>
        )}
      </Pressable>
      {error && <Text className="mt-4 text-red-600">{error}</Text>}
    </View>
  );
}

  errorMessage?: string;

export interface LatLng {
  lat: number;
  lng: number;
}

const EARTH_RADIUS_METERS = 6371000;

export function haversineDistanceMeters(a: LatLng, b: LatLng): number {
  const toRad = (deg: number) => (deg * Math.PI) / 180;
  const dLat = toRad(b.lat - a.lat);
  const dLng = toRad(b.lng - a.lng);
  const lat1 = toRad(a.lat);
  const lat2 = toRad(b.lat);

  const h =
    Math.sin(dLat / 2) ** 2 + Math.cos(lat1) * Math.cos(lat2) * Math.sin(dLng / 2) ** 2;
  const c = 2 * Math.atan2(Math.sqrt(h), Math.sqrt(1 - h));
  return EARTH_RADIUS_METERS * c;
}
```

```typescript
import Geolocation from 'react-native-geolocation-service';
import { haversineDistanceMeters } from './geo.util';
import { Office } from '../offices/officesApi';

export type CrossingEvent = { office: Office; type: 'enter' | 'exit' };

export function startGeofenceWatcher(
  offices: Office[],
  onCrossing: (event: CrossingEvent) => void,
): () => void {
  const insideByOfficeId = new Map<string, boolean>();

  const watchId = Geolocation.watchPosition(
    (position) => {
      const here = { lat: position.coords.latitude, lng: position.coords.longitude };
      for (const office of offices) {
        const [lng, lat] = office.location.coordinates;
        const distance = haversineDistanceMeters(here, { lat, lng });
        const isInside = distance <= office.radiusMeters;
        const wasInside = insideByOfficeId.get(office._id) ?? false;

        if (isInside && !wasInside) {
          onCrossing({ office, type: 'enter' });
        } else if (!isInside && wasInside) {
          onCrossing({ office, type: 'exit' });
        }
        insideByOfficeId.set(office._id, isInside);
      }
    },
    () => {},
    { enableHighAccuracy: true, distanceFilter: 10, interval: 15000 },
  );

  return () => Geolocation.clearWatch(watchId);
}
```

Create `mobile/src/location/locationPingService.ts`. Note on scope: this

```typescript
import Geolocation from 'react-native-geolocation-service';
import { sendLocationPing } from './locationApi';

const PING_INTERVAL_MS = 90000;
let intervalId: ReturnType<typeof setInterval> | null = null;

const MAX_PING_ATTEMPTS = 3;

async function sendWithRetry(dto: Parameters<typeof sendLocationPing>[0]): Promise<void> {
  for (let attempt = 1; attempt <= MAX_PING_ATTEMPTS; attempt++) {
    try {
      await sendLocationPing(dto);
      return;
    } catch {
      if (attempt === MAX_PING_ATTEMPTS) return; // drop the ping — no offline queue, per spec
      await new Promise((resolve) => setTimeout(resolve, 2 ** attempt * 1000)); // 2s, 4s
    }
  }
}

function pingOnce(): void {
  Geolocation.getCurrentPosition(
    (position) => {
      void sendWithRetry({
        lat: position.coords.latitude,
        lng: position.coords.longitude,
        timestamp: new Date().toISOString(),
      });
    },
    () => {},
    { enableHighAccuracy: true, timeout: 15000 },
  );
}

export function startLocationPings(): void {
  if (intervalId) return;
  pingOnce();
  intervalId = setInterval(pingOnce, PING_INTERVAL_MS);
}

export function stopLocationPings(): void {
  if (intervalId) {
    clearInterval(intervalId);
    intervalId = null;
  }
}
```

# Employee Attendance Mobile App

React Native (bare CLI) Android app for the employee attendance & location

   and generated keys/fingerprints specific to your machine.

## Manual native setup (required before the app will run)

- **Google Sign-In** (Task 4): create an OAuth 2.0 **Android** client ID
  in Google Cloud Console using this app's package name and debug/release
  SHA-1 fingerprints, and a separate **Web** client ID. Call
  `GoogleSignin.configure({ webClientId: '<web-client-id>' })` once at
  app startup (e.g. in `App.tsx`) with the **Web** client ID — the
  Android one is registered with Google but never referenced directly in
  code.
- **Location permissions** (Tasks 11, 13): `ACCESS_FINE_LOCATION`,
  `ACCESS_COARSE_LOCATION`, `ACCESS_BACKGROUND_LOCATION`,
  `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION` in
  `android/app/src/main/AndroidManifest.xml`, plus the `<service>` entry
  `react-native-background-actions` requires (copy from its README for
  the installed version).
- **Notifications** (Task 12): Android 13+ requires the runtime
  `POST_NOTIFICATIONS` permission; already requested at first use via
  `notifee.requestPermission()`, no manifest change needed for local
  notifications.
- **Maps** (Task 16): a Google Maps API key with the Maps SDK for Android
  enabled, added as a `<meta-data>` entry in `AndroidManifest.xml`.

## Running

- `npm start` — Metro bundler
- `npm run android` — build and run on a connected device/emulator
  (requires the backend reachable at `API_BASE_URL` above, and an
  emulator/device with Google Play Services for Google Sign-In and Maps)
- `npm test` — unit and component tests (Jest + React Native Testing
  Library) — no device/emulator needed
